# 修改配置文件 `conf/zoo.cfg`

假设存在三台机器：192.168.3.33、192.168.3.35、192.168.3.37，且都下载了zookeeper压缩包。

按 server.id = ip:port:port 修改集群配置文件，三台虚拟机 zoo.cfg 文件末尾添加配置:

```bash
server.1=192.168.3.33:2888:3888
server.2=192.168.3.35:2888:3888
server.3=192.168.3.37:2888:3888
```

根据 id 和对应的地址分别配置 `/tmp/zookeeper/myid`。例如机器 192.168.3.33
```bash
cat /tmp/zookeeper/myid
1
```

# 关闭防火墙

```bash
systemctl stop firewalld
```
# 执行命令

启动 zookeeper 服务端

```bash
sh bin/zkServer.sh start
```

启动 zookeeper 客户端

```bash
sh bin/zkCli.sh
```

查看机器状态（Mode：leader 代表主节点，follower 代表从节点）

```bash
sh bin/zkServer.sh status
```
