# 修改配置
`config/server.properties` 配置
```bash
# Broker 唯一 ID（集群内不能重复）
broker.id=0
# 监听地址（本地学习用）
listeners=PLAINTEXT://localhost:9092
# 日志（Partition 数据）存放目录
log.dirs=/tmp/kafka-logs
# ZooKeeper 地址（你之前装好的）
zookeeper.connect=localhost:2181
# 每个 Topic 默认副本数
default.replication.factor=1
# 每个 Topic 默认分区数
num.partitions=1
```
# 执行命令

等待 zookeeper 启动后，启动 Kafka broker
```bash
bin/kafka-server-start.sh config/server.properties
```
创建 Topic
```bash
bin/kafka-topics.sh \
--bootstrap-server localhost:9092 \
--create \
--topic test-topic \
--partitions 3 \
--replication-factor 1
```
查看 Topic
```bash
bin/kafka-topics.sh --bootstrap-server localhost:9092 --list
bin/kafka-topics.sh --bootstrap-server localhost:9092 --describe --topic test-topic
```
删除 Topic
```bash
bin/kafka-topics.sh --bootstrap-server localhost:9092 --delete --topic test-topic
```
