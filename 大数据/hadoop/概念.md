Hadoop 主要包含 HDFS 和 MapReduce 两大组件，HDFS 负责分布储存数据，MapReduce 负责对数据进行映射、规约处理，并汇总处理结果。

## HDFS

Hadoop Distributed File System，Hadoop 分布式文件系统，简称 HDFS。
![[Pasted image 20260525001655.png]]
### NameNode

它是 HDFS 的**主节点（Master）**：
- **存元数据**：维护整个文件系统的**目录树**、文件与 Block 的映射关系、每个 Block 存在哪些 DataNode 上。
- **对外接口**：处理客户端的文件读写请求（告诉客户端该去哪几个 DataNode 读/写数据）。
- **调度管理**：控制 DataNode 的上下线、Block 副本的创建与均衡。
### DataNode

它是 HDFS 的**从节点（Slave）**：
- **存真实数据**：磁盘上存实际的文件块（Block，默认 128MB 一块）。
- **定期汇报**：启动时和运行中，通过心跳（默认 3 秒）向 NameNode 汇报自己存的 Block 列表。
- **读写管道**：客户端根据 NameNode 的指派，直接和 DataNode 进行数据流的读/写/复制。
### Secondary NameNode

它**定期合并元数据**，可以有多个：
- NameNode 为了性能，把元数据操作先写内存，追加到磁盘的 **Edits Log**。
- 随着时间推移，Edits Log 会巨大，`fsimage`（元数据镜像）就落后很多。
- **Secondary NameNode 定期**：
    1. 从 NameNode 拉取 fsimage + edits log
    2. 在自己内存里合并成新 fsimage
    3. 推回给 NameNode 替换旧的
- **目的**：防止 NameNode 重启时重放超大的 Edits Log 导致启动巨慢。
