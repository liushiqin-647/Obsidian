
# 管理模式

| 维度          | Standalone 模式      | Yarn 模式                  |
| ----------- | ------------------ | ------------------------ |
| **资源管理**    | Flink 独立管理，不依赖外部系统 | 依赖 Hadoop Yarn 进行资源调度与分配 |
| **部署复杂度**   | ⭐ (简单，只需 Java 环境)  | ⭐⭐⭐ (需搭建 Hadoop/Yarn 环境) |
| **弹性伸缩**    | ❌ 不支持，节点固定         | ✅ 支持，可根据负载自动扩缩容          |
| **高可用(HA)** | 需手动配置 ZooKeeper    | 天然支持，由 Yarn 负责故障恢复       |
| **适用场景**    | 开发测试、小规模稳定任务、边缘计算  | 大规模生产环境、已有大数据平台          |

# 执行命令

| 运行模式                    | JobManager 的进程名                      | TaskManager 的进程名         |
| ----------------------- | ------------------------------------ | ------------------------ |
| **Standalone 模式**       | `StandaloneSessionClusterEntrypoint` | `TaskManagerRunner`      |
| **Yarn Session 模式**     | `YarnSessionClusterEntrypoint`       | `YarnTaskExecutorRunner` |
| **Yarn Per-Job 模式**     | `YarnJobClusterEntrypoint`           | `YarnTaskExecutorRunner` |
| **Yarn Application 模式** | `YarnApplicationClusterEntryPoint`   | `YarnTaskExecutorRunner` |
## Standalone mode

在启动集群之前，需要配置 `conf/masters` 和 `conf/workers` 文件

启动集群，会同时启动 JobManager 和 TaskManager 进程：

```bash
./bin/start-cluster.sh
```

启动成功后，可以通过浏览器访问 Web UI：`http://localhost:8081`（具体端口取决于配置）

集群启动后，使用 `flink run` 命令提交你的 JAR 包任务：

```bash
./bin/flink run ./examples/streaming/TopSpeedWindowing.jar
```

停止集群

```bash
./bin/stop-cluster.sh
```

>注：Standalone 还有一种 Application Mode，需要分别使用 `standalone-job.sh` 和 `taskmanager.sh` 脚本来单独启动 JobManager 和 TaskManager，适合对资源隔离要求更高的场景。
## Yarn mode

在使用 Yarn 模式前，必须先确保 Hadoop 的 **HDFS 和 Yarn 服务已经正常启动**。Yarn 模式主要有三种具体的启动形态：

**Session 模式（先开辟资源，再提交任务）**

启动 Yarn Session：

```BASH
# -tm 指定每个TaskManager内存, -s 指定每个TM的slot数, -d 表示后台运行 
bin/yarn-session.sh -tm 1024 -s 4 -d
```

向该 Session 提交作业：

```bash
bin/flink run examples/batch/WordCount.jar
```

停止 Session，需要通过 Yarn 的命令来杀死对应的 Application ID：

```bash
yarn application -kill <application_xxx_id>
```

**Per-Job 模式（单作业独立集群）**

这种模式不需要预先启动 Session，直接使用 `flink run` 命令即可。每提交一个作业，都会单独向 Yarn 申请资源并启动一个独立的集群。

```bash
# -m yarn-cluster 表示以 Yarn 集群模式运行 
bin/flink run -m yarn-cluster -yjm 1024 -ytm 1024 examples/batch/WordCount.jar
```

**Application 模式（生产推荐）**

这是 Flink 1.11+ 引入的新模式，作业的 `main()` 方法直接在集群的 JobManager 中执行。使用 `run-application` 命令提交作业，并通过 `-t` 指定目标平台为 `yarn-application`：

```bash
bin/flink run-application -t yarn-application \
  -Djobmanager.memory.process.size=1024m \
  -Dtaskmanager.memory.process.size=1024m \
  examples/batch/WordCount.jar
```
