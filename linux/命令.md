## awk

awk是一个强大的文本处理工具，以模式-动作对的方式工作。

```
awk 'pattern {action}' file.txt
```
* 对 `file.txt` 的内容按行处理
# grep

在文本中搜索匹配指定模式的行

| 选项       | 用途    | 示例                         | 一句话解释                     |
| -------- | ----- | -------------------------- | ------------------------- |
| **`-i`** | 忽略大小写 | `grep -i "error" log.txt`  | 搜索"error/Error/ERROR"都能匹配 |
| **`-v`** | 反向匹配  | `grep -v "#" config.txt`   | 排除包含"#"的行（如注释）            |
| **`-r`** | 递归搜索  | `grep -r "TODO" src/`      | 在目录及其子目录中搜索               |
| **`-n`** | 显示行号  | `grep -n "bug" file.py`    | 显示匹配行在文件中的行号              |
| **`-E`** | 扩展正则  | `grep -E "error\|warning"` | 支持`\|`、`+`、`?`等正则符号       |
| **`-o`** | 只显示匹配部分 | `grep -o "http://[^ ]*"` | 只提取匹配的文本，不显示整行 |
