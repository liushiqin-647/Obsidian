```c
void *memdup_user_nul(const void __user *src, size_t len)
unsigned long copy_from_user(void *to, const void __user *from, unsigned long n)
```
从用户空间复制写入的数据到内核空间

| 特性    | memdup_user_nul | copy_from_user |
| ----- | --------------- | -------------- |
| 内存分配  | 自动分配            | 需要预先分配         |
| 字符串处理 | 自动添加`\0`        | 需要手动添加         |
| 返回值   | 指向新内存的指针        | 未复制的字节数        |
| 使用场景  | 复制字符串           | 复制任意数据         |
| 错误处理  | 返回 ERR_PTR      | 返回非零值          |
