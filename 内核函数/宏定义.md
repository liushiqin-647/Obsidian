```c
container_of(ptr, type, member)
```
已知某个结构体成员 member 的指针 ptr，container_of(ptr, type, member) 通过 member 在 type 中的偏移（offsetof(type, member)）计算出包含该成员的结构体的起始地址并返回 type*。

```c
list_for_each_entry(pos, head, member)
```
- head 是哨兵节点，形成双向环状链表（空链表时 head->next == head）。
- 每个链表节点包含成员 member，所有节点通过 member 串成链表。
- list_for_each_entry 宏会把 member 指针用 container_of 反推回包含该成员的父结构体，从而直接得到每个节点对应的结构体指针。

```c
INIT_LIST_HEAD(list)
```
把一个 struct list_head 初始化成“空”的环状链表节点（next/prev 指向自己）

```c
test_and_set_bit(n, bmp) 
```
将位图bmp第 n 位置 1，并返回该位原来的值。
