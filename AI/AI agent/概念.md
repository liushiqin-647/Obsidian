
# 三种消息角色

| 角色                | 作用                         |
| ----------------- | -------------------------- |
| **System（系统提示）**  | 设定 AI 的身份、规则和行为准则，在对话开始前生效 |
| **User（用户）**      | 你每次发出的消息，提出任务或问题           |
| **Assistant（助手）** | AI 的回复；也可以预填内容，让 AI 从那里继续  |
![[Pasted image 20260624110148.png]]**关键规则：** User 和 Assistant 消息必须交替出现，对话永远以 User 消息开头。这是 API 调用的硬性格式要求。

# 上下文窗口：AI 的"工作记忆"

每个模型都有一个**上下文窗口（Context Window）**，即它在一次对话中能处理的最大 Token 数量。超过这个上限，模型就会"忘记"最早的内容
