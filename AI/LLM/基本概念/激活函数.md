**激活函数**是神经网络中引入**非线性的数学函数**，用于处理神经元的加权输入信号并决定其输出值，从而使模型能够拟合复杂的数据关系。

### 1. Sigmoid 函数

- **数学公式**：$f(x) = \frac{1}{1 + e^{-x}}$
- **特点**：将输入压缩到 (0, 1) 区间内。
- **缺点**：容易出现梯度消失问题（即反向传播时梯度趋近于零），且计算量相对较大（涉及指数运算）。目前多用于二分类问题的输出层。

### 2. Tanh 函数（双曲正切函数）

- **数学公式**：$f(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$
- **特点**：将输入压缩到 (-1, 1) 区间内，是以 0 为中心的。
- **应用**：相比 Sigmoid，其收敛速度更快，常用于循环神经网络（RNN）中。

### 3. ReLU 函数（线性整流函数）

- **数学公式**：$f(x) = \max(0, x)$
- **特点**：当输入小于 0 时输出为 0，大于 0 时保持原值。
- **优势**：计算极其高效，且在正区间不存在梯度饱和问题。它是目前深度神经网络隐藏层中最常用的激活函数。

### 4. Softmax 函数

- **数学公式**：$f(x_i) = \frac{e^{x_i}}{\sum_{j} e^{x_j}}$
- **特点**：将一个包含任意实数的向量转换为概率分布向量（所有元素之和为 1）。
- **应用**：专门用于多分类任务的输出层，表示样本属于各个类别的概率。

### 5. Leaky ReLU 函数（带泄露的线性整流函数）


- **数学公式**：$f(x) = \begin{cases} x & (x > 0) \\ \alpha x & (x \le 0) \end{cases}$ （其中 $\alpha$ 为一个极小的常数，如 0.01）
- **特点**：解决了标准 ReLU 在负区间输出恒为 0 导致神经元“死亡”的问题，允许负值有微小的梯度通过。
