## 阶段一：基础衔接与工具链转换（第 1-3 个月）

**阶段总目标**：完成从 C/C++ 到 Python/AI 生态的认知与工具转换，跑通 AI 基础流程。

### 1. Python 与 AI 核心库

- [ ] **任务：Python 语法与算法重写**
    - **目标**：体会 Python 动态类型与 C++ 的差异，戒掉指针思维。
    - ️ **执行路径**：用 Python 重写一个以前用 C++ 写过的算法（如排序或链表）。不要纠结面向对象，体会脚本语言的简洁。
- [ ] **任务：NumPy 矩阵运算**
    - **目标**：掌握向量化操作，戒掉 `for` 循环思维。
    - ️ **执行路径**：在 GitHub 搜索 `rougier/numpy-100`，每天刷 10 道题，重点理解广播机制（Broadcasting）。
- [ ] **任务：Pandas 数据清洗**
    - **目标**：掌握 AI 数据预处理基本功。
    - ️ **执行路径**：去 Kaggle 搜索“泰坦尼克号”数据集，跟着 B站/知乎的“Kaggle 泰坦尼克号 Pandas 教程”一步步敲代码。

### 2. 深度学习框架入门

- [ ] **任务：PyTorch 官方入门**
    - **目标**：理解 Tensor 与 Autograd（自动求导）。
    - ️ **执行路径**：阅读 PyTorch 官方文档 **Deep Learning with PyTorch: A 60 Minute Blitz**，跟着敲一遍。
- [ ] **任务：手写全连接网络**
    - **目标**：打通 C++ 指针运算与 AI 矩阵运算的任督二脉。
    - ️ **执行路径**：不使用 `nn.Linear` 等高级 API，只用 `Tensor` 和 `torch.matmul`，配合 `torch.no_grad()` 手动更新权重，实现线性回归。

### 3. 经典 CV/NLP 任务实战

- [ ] **任务：MNIST 手写数字分类**
    - **目标**：跑通“数据准备 -> 模型训练 -> 评估”的完整闭环。
    - ️ **执行路径**：使用 PyTorch 搭建简单的 CNN 或全连接网络，训练至测试集准确率达到 98% 以上。
- [ ] **任务：绘制 Loss 曲线**
    - **目标**：学会观察模型训练状态。
    - ️ **执行路径**：使用 `matplotlib` 记录并画出训练过程中的 Loss 变化曲线。

## 阶段二：核心原理与 AI 工程化突破（第 4-6 个月）

**阶段总目标**：理解大模型核心架构，掌握 RAG 与 AI 应用开发技术栈。

### 1. AI 核心原理

- [ ] **任务：图解 Transformer**
    - **目标**：直观理解注意力机制，不深究复杂数学推导。
    - ️ **执行路径**：阅读 Jay Alammar 的博客 **《The Illustrated Transformer》**（B站/知乎有中文精翻版）。
- [ ] **任务：论文精读与代码实现**
    - **目标**：将数学公式转化为具体的代码逻辑。
    - ️ **执行路径**：在 B站 搜索 **“李沐 论文精读 Attention Is All You Need”**，跟着视频逐行用 PyTorch 实现 Self-Attention 模块。

### 2. RAG（检索增强生成）技术栈

- [ ] **任务：理解 Embedding 与检索本质**
    - **目标**：掌握文本向量化与余弦相似度。
    - ️ **执行路径**：写一个 50 行以内的 Python 脚本，用 `sentence-transformers` 库把几句话变成向量，用 `numpy` 算出哪两句最相似。
- [ ] **任务：搭建本地 RAG 问答机器人**
    - **目标**：掌握大模型外挂知识库的完整工程链路。
    - ️ **执行路径**：看 LangChain 官方文档的 **Build a RAG App** 教程，将本地 PDF/TXT 切分、存入内存向量库，接入大模型 API 实现问答。

### 3. Prompt Engineering 与 AI 平台

- [ ] **任务：掌握提示词工程**
    - **目标**：学会引导大模型输出结构化结果。
    - ️ **执行路径**：总结并测试 3 种常用 Prompt 技巧（Few-shot, CoT, 结构化输出）。
- [ ] **任务：AI 平台实战**
    - **目标**：熟悉主流 AI 应用开发平台。
    - ️ **执行路径**：在 Dify 或 FastGPT 上，通过拖拽和配置，搭建一个完整的 AI 智能客服应用。

## 阶段三：专项突破与 C++ 优势放大（第 7-9 个月）

**阶段总目标**：根据选定方向（AI Infra 或 AI 工程化）进行深度技术攻坚。

### 路线 A：AI Infra（推理引擎/底层优化）

- [ ] **任务：CUDA 编程入门**
    - **目标**：掌握 GPU 编程基础。
    - ️ **执行路径**：B站搜索 **“CUDA 编程入门”**，学会写一个最简单的 `__global__` 向量加法 Kernel，理解 Grid/Block/Thread。
- [ ] **任务：阅读纯 C/CUDA 大模型代码**
    - **目标**：发挥 C++ 优势，理解底层显存优化。
    - ️ **执行路径**：在 GitHub 搜索 **`llm.c`**（Andrej Karpathy 编写），阅读其中关于 KV Cache 和 PagedAttention 的 C 语言实现。

### 路线 B：AI 工程化/MLOps（服务编排/部署）

- [ ] **任务：封装 RESTful API 与流式输出**
    - **目标**：将 AI 模型转化为高可用后端服务。
    - ️ **执行路径**：使用 FastAPI 将阶段二的 RAG 系统封装为 API，并实现 SSE（Server-Sent Events）流式输出，解决大模型响应延迟问题。
- [ ] **任务：容器化部署**

    - ️ **执行路径**：编写 Dockerfile，将 AI 服务容器化，并尝试部署到云服务器。
