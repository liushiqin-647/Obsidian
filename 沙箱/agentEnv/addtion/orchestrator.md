# 编排器（Orchestrator）

> 每节点一个的"沙盒总管"（进程级单例），负责本机所有沙盒的全生命周期。代码：`src/orchestrator/`。

## 职责

| 职责 | 说明 |
|---|---|
| 生命周期 | 创建 / 恢复 / 暂停 / 快照 / Fork / 删除 |
| 状态机 | 保证沙盒任意时刻只处于一个合法状态 |
| 协调子系统 | 指挥 Firecracker、ublk/overlaybd、快照仓库、网络、代理路由 |
| 资源与超时 | 分配/统计 CPU 内存、TTL、自动驱逐空闲超时沙盒 |
| 持久化与恢复 | 记录元数据；重启后恢复"已暂停"沙盒 |
| 可观测性 | 维护运行时计数器，供管理端点与调度器心跳 |

## 状态机（8 态）

```
Creating ─► Running ─┬─► Pausing ─► Paused ─► Resuming ─► Running
                     ├─► Snapshotting ─► Running
                     ├─► Forking ─► Running
                     └─► Killing
```
- 过渡态：Creating/Resuming/Pausing/Snapshotting/Forking/Killing
- 稳定态：Running / Paused
- 只有当前状态等于预期值才允许转移，避免并发踩踏。

## 能力

1. **创建**：从镜像冷启动，或从快照启动（统一启动流程）。
2. **恢复**：暂停的沙盒重新拉起（重建 VM、恢复内存与文件系统、重启 envd）。
3. **暂停**：捕获状态并停 VM，转 Paused（不占资源）。
4. **快照**：对运行中沙盒捕获可复用快照（原创继续跑）。
5. **Fork**：从运行中沙盒的当前状态派生独立新沙盒。
6. **删除**：销毁并清理（独立删除进度，防重复删除）。
7. **TTL/自动驱逐**：后台定时回收超时空闲沙盒。
8. **重启恢复**：启动时对账持久化的暂停记录，重建可恢复的。

## 可靠性设计

| 设计 | 作用 |
|---|---|
| 条件化状态转移 | 当前状态匹配才更新，防并发改乱 |
| 每沙盒句柄加锁 | 同沙盒操作串行化；过渡态等待有超时 |
| 事务式启动 + 回滚 | 启动失败回滚元数据、停止半成品 |
| 镜像引用保护/释放 | 防后台 GC 误删，结束释放 |
| 取消安全 | 关机打断时清理半成品 |
| 删除进度管理 | 防并发重复删除 |
| 重启对账 | 恢复可恢复的暂停记录、清理无效的 |

## 结论

**编排器用受控状态机把"创建/恢复/暂停/快照/Fork/删除"翻译成对 Firecracker、ublk、overlaybd、快照仓库、代理路由的下层调用，同时负责超时驱逐、持久化恢复、指标与失败回滚——是单节点内把各子系统串起来的中枢。**
