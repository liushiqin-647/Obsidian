
| 方法          | 返回什么       | 直观理解        |
| ----------- | ---------- | ----------- |
| `x.shape`   | **张量的形状**​ | 每一维有多大      |
| `x.size()`  | **张量的形状**​ | 和 `shape`等价 |
| `x.numel()` | **元素总数**​  | 张量里一共有多少个数  |
`x.size()` 和 `x.shape`一模一样。区别只是：
- `shape`是 **属性**
- `size()`是 **方法**

👉 **只要在一行里用逗号分隔的表达式，Python 就会打包成 tuple**
